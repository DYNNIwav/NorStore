# NorStore - JavaScript Frameworks Course Assignment

An e-commerce store built with Next.js (App Router), TypeScript, and Tailwind CSS using the Noroff v2 API.

Course: JavaScript Frameworks (Noroff)  
Author: Pål Omland Eilevstjønn  
Class: MAR25FT  

## Features

- Product catalog with live search, tag filtering, and price/rating sorting
- Individual product pages with high-resolution image, discount calculation, and customer reviews
- Shopping cart with persistent state in localStorage and live quantity adjusters
- Checkout success confirmation with generated order reference and cart reset
- Contact form with client-side validation for name, subject, email, and message

## Running locally

```bash
git clone https://github.com/DYNNIwav/NorStore.git
cd NorStore
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
