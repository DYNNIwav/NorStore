# NorStore

Frontend e-commerce application built with Next.js (App Router), TypeScript, and Tailwind CSS for the JavaScript Frameworks course assignment at Noroff.

Author: Pål Omland Eilevstjønn  
GitHub: DYNNIwav  

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
